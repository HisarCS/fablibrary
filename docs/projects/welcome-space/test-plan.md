# Test plan

Every test is recorded on GitHub via **Issues → Test result**.

| # | Stage | Gate criterion | Parameter to change |
|---|---|---|---|
| 1 | Electronics bench test | 10/10 circuits work, 3 LEDs clearly visible | LED type, resistor |
| 2 | Copper tape / GS-24 | 10 cuts, 10 clean peels | – |
| 3 | Comb test | Fits by a child's hand without force or wobble | `SLOT_W` |
| 4 | 3D print | Nose cone and diffuser fit, glow in the dark | `slotW`, `pocketD` |
| 5 | Stickers | Dry, clean adhesion | – |
| 6 | Integrated prototype | An adult assembles it in 15–20 min | – |
| 7 | Pilot (6–8 children) | At least 80% success within 60 min | Assembly order |
