# Lesson plan (60 min)

| Minutes | Activity |
|---|---|
| 0–7 | Show a finished ship: "Which part was made on which machine?" |
| 7–12 | FabLab intro: laser, 3D printer, Roland, electronics. A short live laser cut. |
| 12–20 | Personalization: choosing and applying stickers |
| 20–32 | Copper rails |
| 32–42 | LEDs, polarity check (peer check) |
| 42–48 | Battery, ON, test, troubleshooting |
| 48–55 | Mechanical assembly |
| 55–60 | Lights off, all ships light up together |

Closing message: *"Today you assembled the parts you were given. In the next mission, you will design some of them yourself."*

## Classroom setup
- ~23 students, 3 adults. 5–6 spare finished rockets.
- A "Bug Hunter" sticker for every student who fixes their own circuit.
