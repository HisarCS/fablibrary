# Contribute

This library is developed by the Hisar FabLab team. Workflow for assistants:

1. Test → **Issues → Test result** form
2. Change → new branch, change the parameter in the generator script, run `build.py`
3. Update `CHANGELOG.md`
4. Pull Request → approval → the site updates automatically

Want to make this in your own FabLab? All files are open under CC BY-SA 4.0. Just credit the source.
