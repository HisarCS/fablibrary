# Welcome Space – Mission 01

An LED-lit, personalized desktop spaceship. Grade 4, 60 minutes, ~140 students.

| Folder | Contents |
|---|---|
| `laser/` | Base plate, panel, wing, comb test (SVG, mm) |
| `3d/` | Nose cone, diffuser (OpenSCAD, parametric) |
| `drawings/` | Dimensioned technical drawings, assembly |
| `electronics/` | Electronics notes and test form |
| `stickers/` | BN-20 sticker files |
| `teaching/` | Lesson plan, troubleshooting card |
| `tests/` | Test photos and notes |
| `generators/` | Scripts that generate every SVG |
| `kit-list.md` | Parts per kit and post-test parameter map |

To regenerate (from repo root): `python projects/welcome-space/generators/build.py`

Website: https://hisarcs.github.io/fablibrary/projects/welcome-space/
