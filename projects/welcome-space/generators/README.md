# Generators

All laser SVGs and drawings are generated by these scripts. Do not edit the SVGs by hand.

| Script | Generates | Key parameters |
|---|---|---|
| `base_diffuser_comb.py` | base plate laser, comb test, base + diffuser drawing | `SLOT_W`, `SLOT_L`, `WSLOT_L` |
| `panel_nosecone.py` | panel laser, panel + nose cone drawing, nose cone SCAD | panel profile `P` |
| `wing.py` | wing laser and drawing | wing profile `K` |
| `assembly.py` | assembly drawing | – |
| `printables.py` | GS-24 copper band, BN-20 sticker sheet, troubleshooting card | band layout, sticker positions |
| `student_card.py` | picture-first student step card (A4) | tile drawings, text |
| `hero.py` | day/night and personalization illustrations | colors, `deco` styles |

`3d/v1_diffuser.scad` is a hand-maintained parametric file.

Run: `python projects/welcome-space/generators/build.py`
